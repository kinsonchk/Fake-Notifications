Audit of the current app (signs found, where they live)

Color

  • Dark surfaces tinted green (Night #19221D, NightSurface #253129, theme/Color.kt): the whole app reads green, so the meadow can't stand out
  • Green everywhere: primary, selection, status pill, bars, tab pill, link text, settings icon tiles all use primary or primaryContainer
  • Rule stripes in a second color family per rule (common/AppRuleRow.kt:73,101)
  • Opened/swiped bar uses tertiary earth next to primary green (stats/StatsScreen.kt OpenedSplitBar)

Icons

  • 💚 emoji as the Health icon (home/HomeScreen.kt:188, common/HealthLoss.kt:101, overlay/CatchOverlay.kt:153)
  • Text glyphs as icons: › (Settings, Rules, Home setup), ← back links, ○ setup rows, ✕ Remove, ▾, ⌄ ⌃, ‹ Earlier / Later ›, ● in the status pill, ✓ Allowed, Below ground ↓
  • Settings link icons inside tinted rounded tiles (settings/SettingsScreen.kt SettingsLink)

Spacing and radius

  • Off-grid values: card padding 18, gaps 10/14/3, tab padding 7/10, icon tile radius 13, link radius 22, dialog radius 26
  • Radii vary without nesting: 20 cards, 22 links, 16 tiles, 14 tabs, 12 segments, 50% pills, 26 dialog
  • A card around nearly every item: Settings is five stacked cards, Rules is one card per app

Copy

  • You got caught lacking! (strings.xml) exclamation
  • Trailing periods on short labels: "Pausing takes a 10-second confirmation.", "Health is at zero.", "No extra catch for 5 s.", "Your catch choice is waiting."
  • Long helper paragraphs under controls (Stats scope, Difficulty, Notification rules header)
  • Home shows Health three ways: meadow, 100/100, progress bar

Type

  • -0.6sp letter spacing applied to every serif size including 26sp metric tiles (theme/Type.kt:10)
  • Serif used for figures inside small tiles (difficulty %, metric cards), where it competes with the page title
  • Platform FontFamily.Serif/SansSerif: nobody chose the faces, they change per phone maker

Components

  • Stat cards of equal width with a mini bar inside one of them
  • Pill chips for meadow actions (Whirlwind, Rain, Explore, Call squirrel) look like filter chips
  • Filled primary difficulty tile is the loudest thing on Settings

Not slop, kept

  • The meadow, the fishing scene, the serif page heading idea, the two-destination caught flow, the copy voice
